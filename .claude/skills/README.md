# Skills

Panduan kerja untuk asisten AI (Claude Code) di repositori ini. Setiap skill berada di folder sendiri dengan berkas `SKILL.md`.

| Skill | Kapan dipakai | Sumber |
|---|---|---|
| `repo-conventions` | Sebelum commit, push, pull request, atau mengubah dokumentasi | Ditulis untuk proyek ini |
| `kaggle-nlp-notebook` | Membuat atau mengubah notebook di `notebooks/` | Ditulis untuk proyek ini |
| `indonesian-text-preprocessing` | Notebook 01 dan kode yang menghasilkan `clean_text` | Ditulis untuk proyek ini |
| `text-classification-evaluation` | Notebook 02, 03, dan pemodelan Part 2 | Ditulis untuk proyek ini |
| `ui-ux-professional` | Merancang atau membangun layar aplikasi Part 2 | Ditulis untuk proyek ini |
| `frontend-design` | Arah visual antarmuka Part 2 | [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design), Apache 2.0, tanpa perubahan |

Aturan di `CLAUDE.md` berlaku di atas semua skill.
